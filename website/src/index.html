Features

Everything the weighing workflow needs

What the WeighingQR mobile app does today, from identifying a packet to reviewing its records.

Product QR Scanning

Identify each seed packet by scanning the QR code printed on it with the phone's camera.

Before & After Weight

Record the packet before filling and the filled packet after, each with a photo. Type the weight or read it from the scale display with the camera.

Weight Difference

The difference between the after and before weights is calculated and saved with the record.

Measurement History

The History tab lists saved weight records with their totals and the average difference.

Analytics

Review total and completed measurements, average and minimum/maximum difference, and the difference by seed type.

Settings & Connection

Edit your profile, check whether the server connection is live and view the configured server address.

Product Information

Scan a packet to see its seed type, batch, storage location and, once weighed, its before, after and difference values.

Connected Data

Measurements are saved to the WeighingQR server when the connection is working, so they appear in the admin dashboard and the desktop app.

This website explains and distributes the apps. Weighing and QR scanning happen in the apps, not on this website.

How it works

From QR code to measurement record

Every packet follows the same path in the Weigh & Record workflow.

  1. Product QR ScanScan the packet's QR code
  2. Product IdentificationThe packet and its batch are looked up on the server
  3. Before WeightWeigh the empty packet, then take a photo
  4. After WeightWeigh the filled packet, then take a photo
  5. Weight DifferenceAfter minus before is calculated
  6. Save RecordSaved to the server and linked to the packet
  7. History & AnalyticsReview records and statistics

Records are stored online only when the app can reach the WeighingQR server and the save succeeds. The app shows the connection state on the Dashboard and in Settings, and confirms each saved measurement.

Android app installation guide

You need an Android phone with a camera and an internet connection (mobile data or any Wi-Fi).

Install the app

  1. 1
    Open this website on your Android phone.
  2. 2
    Tap Download Android APK.

    You will find it in the Downloads section above.

  3. 3
    Wait for the download to finish.

    The file is about 312 MB, so use a good connection.

  4. 4
    Open the downloaded APK file.

    Tap the download notification, or open it from the Downloads folder in your file manager.

  5. 5
    Allow the installation if Android asks.

    If you see a message about installing unknown apps, open the offered settings and allow it for the browser or file manager you are using, then go back.

  6. 6
    Tap Install and wait for it to finish.
  7. 7
    Open WeighingQR.

Create your account and sign in

  1. 8
    Create an account.

    The app opens on the Sign In screen. Tap Create Account, enter your Full Name, Email Address, Password and Confirm Password, then tap Create Account. The app shows “Account created!” and returns to Sign In.

  2. 9
    Sign in with the same email address and password.

    The app then opens the Dashboard. Next time, you stay signed in.

Weigh and review

  1. 10
    Check the server connection on the Dashboard.

    It should show System Online. If it does not, see “What should I do if the server is offline?” in the FAQ.

  2. 11
    Choose Weigh & Record or Product Info.

    Weigh & Record captures a new measurement. Product Info only shows a packet's details.

  3. 12
    Scan the packet's QR code.

    Allow camera access the first time the app asks.

  4. 13
    Capture the before and after weights.

    Weigh the empty packet and enter the weight, typed or read with 📷 Scan Scale Display and confirmed, then tap Next — Before Photo and take the photo. Then weigh the filled packet the same way: Continue — After Weight, Next — After Photo.

  5. 14
    Save the record.

    Check the after photo, then tap Save Measurement. The app confirms “Saved to the server and linked to this packet” and shows the before, after and difference values.

  6. 15
    Review records in History and Analytics.
  7. 16
    Use Settings for your profile and the connection status.

    Leave the server address unchanged unless your administrator tells you otherwise.

An internet connection is needed to sign in and to save measurements. You do not need to be on the same Wi-Fi as anyone else; the app connects to the WeighingQR server over the internet.

Already have an older or test version installed? Android may refuse to install over it. Uninstalling it deletes what that app stored on the phone, including your saved sign-in and server setting. Measurements already saved on the server are not deleted, but finish or note any unsaved work first.

Compatibility depends on the device. The app needs Android 7.0 or later; not every phone model has been tested.

Windows desktop app installation guide

For Windows 10 or 11 (64-bit). The desktop app is installed for your Windows user only and needs no administrator rights.

  1. 1
    Open this website on the Windows laptop or PC.
  2. 2
    Click Download Windows App.
  3. 3
    Wait for the installer to download.

    The file is SeedManagement-Setup-0.1.1.exe (about 111 MB).

  4. 4
    Open the installer.

    The installer is not code-signed, so Windows may show “Windows protected your PC”. If you downloaded it from this website, click More info, then Run anyway. You can compare the file with the SHA-256 shown in the Downloads section.

  5. 5
    Follow the installation wizard.

    You can keep the default installation folder. A desktop shortcut and a Start menu entry are created.

  6. 6
    Launch Seed Management.
  7. 7
    Sign in with an admin account.

    Use an account created by a Superadmin in the WeighingQR admin dashboard. Accounts created in the Android app cannot sign in to the desktop app.

  8. 8
    Confirm the connection.

    The sign-in screen shows the server address and the app version. After sign-in, the sync status shows that records were downloaded; Sync now refreshes them.

  9. 9
    Work with the records.

    All admin accounts can view records, including Before Weight and After Weight from mobile weighings. Superadmin accounts can also add and edit records. The app keeps Seed_Management.xlsx in your Documents folder; use Show in folder or Save a copy to open it.

  10. 10
    Check that saved records match.

    A packet weighed on the phone should show the same values in the desktop app and in the admin dashboard after the next sync.

The desktop app does not weigh or scan packets. Weighing happens in the Android app; the desktop app manages the resulting records.

FAQ

Frequently asked questions

Is the Android APK different from the Windows application?

Yes. They are two separate apps with separate installers. The Android app (.apk) scans packet QR codes and records before and after weights. The Windows app, “Seed Management” (.exe), is a desktop records manager for admin accounts. Neither file can be used on the other platform.

Do I need to be on the same Wi-Fi network?

No. Both apps connect to the WeighingQR server over the internet, so any working connection is enough: mobile data or any Wi-Fi.

How do I install the APK?

Download it on the phone, open the file, allow installation from your browser or file manager if Android asks, then tap Install. See the Android installation guide for every step.

How do I install the Windows application?

Download SeedManagement-Setup-0.1.1.exe, open it (choose More info → Run anyway if SmartScreen warns you) and follow the wizard. See the Windows installation guide.

How do I create an account and sign in?

Android: on the Sign In screen tap Create Account, enter your full name, email address and password (twice), then sign in with that email and password.

Windows: the desktop app has no self sign-up. It needs an admin account created by a Superadmin in the admin dashboard. Accounts created in the Android app do not work there.

Where can I view saved measurement records?

On the phone, in the History and Analytics tabs; Product Info shows one packet's values after you scan it. Admin accounts can also see records in the admin dashboard and in the Windows desktop app.

What should I do if the server is offline?

Check that the phone or PC has internet access, then wait a moment and try again. After a period without use, the server can take up to about a minute to respond to the first request. On the phone, use Retry on the Dashboard, or check the connection status in Settings.

A measurement only counts as saved when the app confirms it. If the connection drops during a weighing, scan the same packet again later: the app resumes the unfinished weighing from what the server already has.

Why does Android warn about installing an APK?

Android warns about every app installed from outside the Play Store, which is how this app is distributed. Install it only from this website. You can confirm the file is genuine by comparing its SHA-256 checksum with the one shown in the Downloads section.

Ready to start weighing?

Install the Android app on the phones used for weighing, and the Windows app on the PCs that manage records.
